# tylxr_log

## Introduction
tylxr_log is a mod for ox_lib designed for FiveM servers that want to utilize Grafana and Loki for logging. This mod helps in efficiently logging, managing, and visualizing player actions.

## Features
- Seamless integration with Grafana and Loki
- Easy installation and setup
- Real-time logging and monitoring

## Prerequisites
- FiveM server
- ox_lib
- Grafana
- Loki

## Installation
1. Download the repository.
2. Drop `bufferprocessing.lua` and `server.lua` into `ox_lib/imports/logger`.

## Usage
1. Configure your Grafana and Loki instances.
2. Start your FiveM server.
3. Monitor your logs in Grafana.
